# Aya v0.1.0

[日本語](#日本語) · [English](#english)

## 日本語

音型を作り、聴きながら変形し、一曲へ並べるWindows向け制作アプリの初公開版です。

- 音符の直接編集と、ユークリッド・アルペジオ・和音進行の生成。
- 回転、逆行、移調、反転、伸縮、決定的な確率。生成結果を音符に確定して修正できます。
- 複数トラックと反復クリップ、微分音・EDO音階、内蔵楽器とWAVサンプル。
- 音量・定位・カットオフのオートメーション、テンポ同期ディレイ、PC鍵盤の演奏と録音。
- 素材を含む保存と再読込み、元に戻す・やり直す、自動回復。
- ステレオWAV・トラック別WAV、SMF MIDIファイルの入出力。

`Aya-Windows-x64.zip` を展開し、`Launch.cmd` をダブルクリックしてください。
GHCや端末の操作は不要です。保存後に `Close.cmd` でアプリを終了できます。
付属の40小節制作例「硝子の潮 — Glass Tides」は編集可能です。

音の計算と音楽の処理は通常のHaskell/GHCで実装しています。画面はブラウザー、
音声は別のネイティブプロセスから出力します。Windows x64・48 kHz固定の初版です。
画面は現在日本語です。公式サイトと開発者ガイドは日本語・英語で読めます。
VST、外部MIDI機器、複数テンポの編集には対応していません。

Aya自身のソースと制作例はMITです。依存物は別ライセンスです。GNU MPは交換可能な
LGPL-3.0-or-laterのDLLとして、完全な対応ソースと通知をZIPに含めています。
詳しくは同梱の `THIRD-PARTY.md` を参照してください。

## English

The first public release of a Windows studio for creating patterns, hearing
variations and arranging a complete piece.

- Direct note editing plus Euclidean rhythms, arpeggios and chord generation.
- Rotation, interval reversal, transposition, inversion, stretching and seeded
  probability. Materialize generated results and edit individual notes.
- Multiple tracks and looping clips, microtonal/EDO scales, built-in instruments
  and embedded WAV samples.
- Gain, pan and cutoff automation, tempo-synced delay, PC keyboard performance
  and note recording.
- Self-contained project save/reopen, undo/redo and local recovery.
- Stereo WAV, individual track stems and SMF MIDI file import/export.

Extract `Aya-Windows-x64.zip` and double-click `Launch.cmd`. No Haskell setup or
terminal knowledge is needed. Save your project, then use `Close.cmd` to close
the app and audio worker. The original 40-bar **Glass Tides** example is editable.

Musical semantics and audio samples are computed by ordinary Haskell/GHC. The
editor runs in a browser and the native audio worker runs separately. This
release targets Windows x64 at fixed 48 kHz. The app UI is currently Japanese;
the website and developer guides are bilingual. VST hosting, external MIDI
hardware and multitempo editing are not implemented.

Aya's own source and example use MIT. Dependencies retain their licenses.
GNU MP is a replaceable LGPL-3.0-or-later DLL; its complete corresponding source,
original notices and replacement instructions are included in the ZIP.
See `THIRD-PARTY.md` before redistribution.

## Files

- `glass-tides.aya.json` — the editable original example.
- `SHA256SUMS.txt` — SHA-256 checksums for those three files.
